## Correção necessária no HostGator

No backend, conferir `deploy/wfc_sistema/api/config/local.php` (fora do Git) ou as variáveis equivalentes: `WFC_DB_HOST`, `WFC_DB_NAME`, `WFC_DB_USER` e `WFC_DB_PASS`. Para uma API PHP hospedada na mesma conta, o host normalmente deve ser o host MySQL indicado no cPanel, frequentemente `localhost`; o nome do banco e do usuário devem incluir o prefixo da conta cPanel. A porta padrão é `3306`.

Se a conexão for feita externamente pelo MySQL Workbench, o cPanel precisa liberar o IP público atual em **Remote MySQL** e o servidor/porta/usuário devem ser os informados pelo HostGator. Essa regra de allowlist é aplicável ao Workbench, mas não substitui a configuração da API PHP. O desktop continua acessando apenas HTTPS.

Após corrigir o backend, validar novamente `/health` esperando HTTP 200 e então testar `/auth/login` no aplicativo. Nenhuma senha de cPanel, FTP ou banco deve ser commitada no repositório.
